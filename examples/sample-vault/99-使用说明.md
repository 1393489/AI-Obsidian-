# 怎么用这个库

← 返回 [[00-总索引]]

## 三个入口

1. **[[00-总索引]]** —— 项目地图 + 主题分类 + 时间线，开工第一站。
2. **10-项目/** —— 每个工作目录一篇，列出该目录下所有会话、主要文件、反复出现的问题。
3. **30-主题/** —— 跨会话复现的报错与热点区域，踩坑前先搜这里。

## 页面里字段的含义

| 字段 | 含义 |
|---|---|
| 会话ID | 采集器给的稳定标识，用于对回原始存档 |
| 轮次 | 一次「用户发问 → 助手干活」 |
| 工具调用 | 会话里所有工具执行次数（含失败） |
| 报错 | 工具返回 is_error 或文本里匹配到错误样式的行 |

## 内容从哪来

本库由 `memloom` 从本机 AI 编码会话存档生成，**不使用大模型**：
页面上的请求、命令、报错、文件路径都是从原文里抽出来的真实内容，
所以不会有「看起来通顺但编的」摘要，反过来也不会替你想出漂亮的主题名。

## 数据来源

- `__auto__` → `~workspace\notes\raw`

## 重新生成

```bash
memloom build --out <本库路径>
```

带 `generated by memloom` 标记的文件会被覆盖；你自己加的笔记不会被删除。
